FAQ

Questions,
answered

Yes. Meezan is built from the ground up on Islamic finance principles. The Zakat calculator follows scholarly consensus — both gold (87.48g) and silver (612.36g) Nisab standards are supported. No interest-based (riba) calculations are ever performed. Sadaqah types align with classical Islamic jurisprudence.

All data is stored in Firebase Firestore with per-user security rules — no one else can read your data. Firebase Auth handles sign-in securely (email/password + Google OAuth). Group data uses top-level Firestore collections with member-only access rules. Your data is never sold or shared with third parties.

Meezan supports 20+ languages including Arabic (full RTL layout flip), Urdu (RTL), Hindi, Tamil, Telugu, Malayalam, Bengali, English, French, Turkish, Malay, and Indonesian. The i18n system uses data-i18n attributes for seamless switching from the Settings page. Changing to Arabic mirrors the entire layout to RTL.

The Family Hub lets the account owner invite members via email or a shareable link. Roles include Owner, Member, and View-only. For shared group expenses (Haj trips, household bills), the Groups page handles Splitwise-style settlement tracking with real-time Firestore sync. Groups are top-level Firestore collections — not nested under any user — so all members have equal access.

The current version is a fully responsive web app — it works beautifully on mobile browsers at meezan-final.vercel.app. A PWA (Progressive Web App) with offline support and home-screen installation is on the roadmap. A native React Native / Flutter app is planned as a future feature.

Meezan tracks your Hawl — the one lunar year a Muslim must hold wealth above the Nisab threshold before Zakat becomes due. When your Hawl completes, a notification fires. The Notifications page lets you configure 13 alert types with custom times, all synchronized to the Hijri calendar. Zakat al-Fitr reminders trigger 3 days before Eid al-Fitr automatically.
